# 📚 Book Shelf

A simple Java console application for managing a collection of books. This project allows users to add, view, search, and remove books using basic Java programming concepts.

## ✨ Features

* Add books to the shelf
* View all books
* Search books by title
* Remove books
* Simple console-based interface

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner

## 📁 Project Structure

```text
book-shelf/
│── BookShelf.java
│── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/book-shelf.git
```

2. Go to the project folder:

```bash
cd book-shelf
```

3. Compile the Java file:

```bash
javac BookShelf.java
```

4. Run the program:

```bash
java BookShelf
```
